# Alinam 💖

Romantik 3 səhifəlik barışıq saytı.

## Fayllar
- `index.html` – bütün sayt (tək fayl)
- `music.mp3` – sənin əlavə edəcəyin mahnı (adı mütləq `music.mp3` olmalıdır)

## Quraşdırma
1. `index.html` içində `PHONE` dəyişənini öz WhatsApp nömrənlə dəyiş (`994501234567` formatında).
2. Mahnı faylını bu qovluğa `music.mp3` adı ilə at.
3. GitHub-da: **Settings → Pages → Branch: main / root → Save**.
4. Bir neçə dəqiqə sonra link hazır olur: `https://ISTIFADECI_ADI.github.io/REPO_ADI/`

## Video
Videonu `video.mp4` adı ilə eyni qovluğa at. Saytın küncündə kiçik çərçivədə səssiz oynayır, toxunanda böyüyür və səsi açılır (mahnı dayanır). Ölçü 25 MB-dan kiçik olsun.
